# DSCI 552 Homework 5

This repository contains my solution for Homework 5 in DSCI 552.

## Contents

The notebook includes:

- Decision tree classification using the Acute Inflammations dataset
- IF-THEN rule extraction
- Cost-complexity pruning
- Communities and Crime data preprocessing
- Ordinary least squares regression
- Ridge and LASSO regression
- Principal component regression
- XGBoost regression
- Test error comparison

## Repository Structure

- `notebook/Joshi_Nishtha_HW5.ipynb`: completed homework notebook
- `data/`: datasets used in the notebook
- `requirements.txt`: required Python packages

## Running the Notebook

Install the required packages:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebook/Joshi_Nishtha_HW5.ipynb` and run the cells in order.
